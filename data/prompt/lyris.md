# lyris

请识别并提取我提供的媒体文件中的歌词，并严格按标准 LRC 格式 输出。

要求如下：

1. 歌词中繁体中文需要转成简体中文
2. 需要带时间戳：精准识别每行歌词的起始时间，格式为 [mm:ss.xx]。
3. 按语义合并分行（核心）：请根据上下文语义和视觉美观度进行分行。切忌将句子切得太碎，如果乐句过短，请将其与前后文合并为一行（短语间可用空格隔开），如果太长需要合理切分，确保每一行都是一个完整的语义意群，且长短适中。
4. 反复唱一句的时候，只用保留第一遍
5. 纯净输出：直接输出 LRC 文本，不要有任何多余的解释或对话。
6. 必须深度搜索，深度思考，严格参考歌词内容，确保歌词识别的准确度
